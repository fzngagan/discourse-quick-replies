# Quick Replies

Shows saved filler sentences ("Happy to help!", "Feel free to reach out if you need anything else.") as clickable bubbles under the composer. Clicking a bubble inserts its text at the cursor.

## Settings

- **quick_replies_groups**: the groups whose members see the bubbles (default: staff). Membership is resolved on the server, so group IDs never reach the browser.
- **quick_replies**: the sentences. Each has a `text` and an optional short `label` for the bubble.
